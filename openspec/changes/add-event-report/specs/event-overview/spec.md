# Spec Delta

## MODIFIED Requirements

### Requirement: "Záró riport" tab

The event tab bar SHALL show "Záró riport" as an enabled tab linking to `/events/<id>/report`.

#### Scenario: Opening the report tab

- **WHEN** the admin clicks "Záró riport" on an event page
- **THEN** `/events/<id>/report` opens with the tab marked as current
